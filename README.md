# atlas-infra

Infrastructure as code for Atlas, provisioned via Pull Request. Defines the local experimentation
cluster (kind), namespaces and service dependencies (e.g. PostgreSQL). It provisions resources only —
application deployment lives in `atlas-gitops` + Argo CD.

## Contents

- `kind-config.yaml` — declarative local cluster definition (NodePort 30080 mapped to the host).
- `bootstrap.sh` — recreates the whole local environment in one command: kind cluster → Argo CD →
  root Application (app-of-apps). After it runs, Argo CD reconciles every service back from git.
- `services/` — Terraform root module. `main.tf` configures the providers; per-service files
  (`svc-<name>.tf`, generated by atlas-api via PR) call the reusable module.
- `modules/service/` — reusable module: a namespace; a `ghcr-pull` image pull secret (dockerconfigjson,
  so private GHCR images can be pulled); and, when enabled, a PostgreSQL instance. All secrets are
  generated/supplied at apply time and kept in tfstate — never committed.
- `.github/workflows/terraform.yml` — `terraform plan` on PRs, `terraform apply` on merge to main,
  on a **self-hosted runner** (a cloud runner cannot reach the local kind cluster).

### Required secrets (repository → Settings → Secrets)

- `GHCR_PULL_USERNAME` / `GHCR_PULL_TOKEN` — a username and a token with `read:packages`, used to build
  the `ghcr-pull` image pull secret in each service namespace. Passed to Terraform as
  `TF_VAR_ghcr_username` / `TF_VAR_ghcr_token`. Without them the pull secret is skipped and private
  images fail to pull.

## Provisioning flow

```
atlas-api → opens a PR adding services/svc-<name>.tf → human review + merge → runner: terraform apply → kind
```

The merge is the human gate; Terraform never runs before it. `tfstate` is local to the runner and
gitignored (it may contain secrets).

## Run

> Requires the Docker daemon running.

```bash
# Full environment from scratch (cluster + Argo CD + apps), idempotent:
./bootstrap.sh

# Or just the cluster:
kind create cluster --config kind-config.yaml
kind delete cluster --name atlas-local
```

## Test

kind version
